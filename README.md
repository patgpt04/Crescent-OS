# 🌙 Crescent OS

Crescent OS is my personal operating system — a set of rules, prompts, and task workflows — stored in GitHub so it stays organised and versioned over time.

## What’s in here
- **master-prompt.md** — the main rules of Crescent OS (how tasks, modes, and formatting work)
- **agent-instructions.md** — how Crescent should behave (tone, structure, constraints)
- **task-console.md** — the live Task Console format (my dashboard)

## How I use this (simple)
1. Open **task-console.md**
2. Update Today’s Tasks + Primary Focus
3. Work top-down through Today’s Tasks
4. Mark completed tasks with ✅
5. Only run **NEW DAY** when I explicitly say so
